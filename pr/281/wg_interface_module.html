community.openwrt.wg_interface module – Manage WireGuard/AmneziaWG identity keys, interface UCI sections and WAN ingress firewall rules

Note

This module is part of the community.openwrt collection (version 1.9.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install community.openwrt. You need further requirements to be able to use this module, see Requirements for details.

To use it in a playbook, specify: community.openwrt.wg_interface.

New in community.openwrt 1.9.0

Synopsis

  • Manages WireGuard/AmneziaWG identity keys, interface UCI sections and the WAN ingress firewall rule for each interface’s listen port.

  • The module performs the following steps in order

    1. Determine the protocol (wireguard by default) and the ubus key server from the configured interfaces.

    1. Resolve the host identity key, reading it from every managed interface, failing on a hard mismatch (two distinct keys), otherwise reusing the single existing key or generating a fresh one via ubus, and deriving and reporting the public key.

    1. Apply the identity key to every managed interface (propagating it to interfaces missing one, or a fresh key on force_rekey).

    1. Remove interfaces whose state is absent, dropping the interface section, its peer sections and its WAN ingress rule.

    1. Write each interface UCI section, including AWG 3.x/3.1 options when proto=amneziawg, and ensure the WAN ingress ACCEPT rule for its listen port (unless manage_firewall=false).

    1. Resolve or generate a per-peer pre-shared key (genpsk) for each peer skeleton, reusing an existing on-device PSK, and return them keyed by interface name.

  • Implemented in ucode and run directly on the OpenWrt target.

  • For the available WireGuard UCI config options see https://openwrt.org/docs/guide-user/services/vpn/wireguard/start.

Note

This module has a corresponding action plugin.

Requirements

The below requirements are needed on the host that executes this module.

  • ucode, ucode-mod-uci and ucode-mod-ubus on the target.

  • The wireguard ubus object (provided by rpcd-mod-wireguard with rpcd running, or the amneziawg object) to generate identity keys and peer PSKs.

Notes

Note

  • The module writes UCI configuration only; it does not bring the interface up or establish tunnels.

  • The identity key and peer PSKs are generated via ubus; the wireguard object is used as a fallback when the requested amneziawg object is not available.

  • It is an intended design decision that all managed interfaces on a host share the same private key (and therefore the same public key), while each peer gets its own distinct pre-shared key. This keeps monitoring and peer mapping simple. The host is identified by one public key, and every peer link is identified by its unique PSK.

  • Template options (*_tpl) use ucode’s native template engine (Jinja-style {{ ... }} / {% ... %}).

Examples

# Hub: resolve/write the identity key and a hub interface section, then
# generate a per-spoke peer PSK for each of the two spokes
- community.openwrt.wg_interface:
    managed_interfaces: [wg0]
    interfaces:
      - name: wg0
        proto: wireguard
        listen_port: 51820
        addresses:
          - "10.8.0.1/24"
    peers:
      - iface: wg0
        section: spoke1
      - iface: wg0
        section: spoke2

# Two independent p2p links on one host: each link is its own interface with
# its own listen port, identity key (shared host-wide) and per-link peer PSK
- community.openwrt.wg_interface:
    managed_interfaces: [wg_l1, wg_l2]
    interfaces:
      - name: wg_l1
        proto: wireguard
        listen_port: 51821
        addresses:
          - "10.9.0.1/30"
      - name: wg_l2
        proto: wireguard
        listen_port: 51822
        addresses:
          - "10.10.0.1/30"
    peers:
      - iface: wg_l1
      - iface: wg_l2

Return Values

Common return values are documented here, the following are the fields unique to this module:

Key

Description

diff

list / elements=dictionary

List of before/after diffs (private keys redacted), one entry per changed section.

Returned: when diff mode and changes were detected

firewall_changed

boolean

True if any WAN ingress firewall rule was created or modified.

Returned: always

interfaces

list / elements=string

Names of (re)written interface sections.

Returned: always

psks

list / elements=string

Resolved (not stored) peer pre-shared keys, as a list parallel to peers (psks[i] is the key for peers[i]). The controller zips the two lists to distribute each shared key to both ends.

Returned: when peers is given

public_key

string

Host identity public key.

Returned: always

removed_interfaces

list / elements=string

Names of interfaces removed because their interfaces[].state was absent.

Returned: when any interface state is absent
