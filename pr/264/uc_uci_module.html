community.openwrt.uc_uci module – Controls OpenWrt UCI (ucode implementation)

Note

This module is part of the community.openwrt collection (version 1.8.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install community.openwrt. You need further requirements to be able to use this module, see Requirements for details.

To use it in a playbook, specify: community.openwrt.uc_uci.

Synopsis

  • Controls OpenWrt UCI using the native ucode uci module (cursor).

  • Supports the same commands and options as community.openwrt.uci, but the module is implemented in ucode and emits Ansible module JSON directly, avoiding the JSON corruption that can affect long diffs in the shell implementation.

  • Requires ucode and ucode-mod-uci on the target (present on all modern OpenWrt builds with fw4).

Note

This module has a corresponding action plugin.

Requirements

The below requirements are needed on the host that executes this module.

  • ucode and ucode-mod-uci on the target.

Parameters

Parameter

Comments

autocommit

boolean

Whether to automatically commit changes.

Without it, changes are staged and persist only if command=commit is run (or another module invocation with autocommit).

Choices:

  • false ← (default)

  • true

command

aliases: cmd

string

uci command to execute.

The default is set if value is passed, otherwise the default is get.

Choices:

  • "absent"

  • "add"

  • "add_list"

  • "batch"

  • "changes"

  • "commit"

  • "del_list"

  • "export"

  • "find"

  • "find_all"

  • "get"

  • "import"

  • "rename"

  • "reorder"

  • "revert"

  • "section"

  • "set"

  • "show"

config

string

Config part of the key.

If not specified, extracted from key.

find

aliases: find_by, search

any

Value(s) to match sections against.

Option value to find if option is set. May be list.

Dict of options/values if option is not set. Values may be list.

Lists are compared in order.

Required when command=find or command=section.

keep_keys

aliases: keep

list / elements=string

Space separated list or list of keys not in value or find to keep when replace=yes.

key

string

The uci key to operate on.

Takes precedence over config, section and option.

If not specified, constructed as config.section.option.

merge

boolean

Whether to merge or replace when command=import.

Choices:

  • false ← (default)

  • true

name

string

New name when command=rename or command=add.

Desired name when command=section. If a matching section is found it is renamed, if not it is created with that name.

operations

list / elements=dictionary

added in community.openwrt 1.9.0

List of sub-operations to execute in a single module invocation.

Each operation supports the same options as a standalone module call (that is command, config, section, option, value, find, type, name, keep_keys, replace, set_find, unique, merge) except the operations and redact_keys options themselves.

Operations are executed in order on a single cursor; changes are committed once at the end if autocommit is set or if any operation is command=commit.

option

string

Option part of the key.

If not specified, extracted from key.

redact_keys

list / elements=string

added in community.openwrt 1.9.0

List of option names whose values are replaced by REDACTED in the diff output. Useful to avoid exposing secrets such as WireGuard private keys or passwords in the module result.

replace

boolean

When command=set or command=section, whether to delete all options not mentioned in keep_keys, value or find when set_find=true.

Choices:

  • false ← (default)

  • true

section

string

Section part of the key.

If not specified, extracted from key.

set_find

boolean

When command=section whether to set the options used to search a matching section in the newly created section when no match was found.

Choices:

  • false ← (default)

  • true

type

string

Section type for command=section, command=find and command=add.

If not specified, defaults to the value of section.

unique

boolean

When command=add_list, whether to add the value if it is already contained in the list.

Choices:

  • false ← (default)

  • true

value

any

The value for various commands.

Notes

Note

  • This module is an alternative implementation of community.openwrt.uci written in ucode. Prefer it when the shell module produces corrupted or truncated JSON for very large configurations.

  • The export, show, import and batch commands shell out to the uci binary to process or produce plain-text UCI. They are therefore not subject to the JSON-staging, check mode and diff handling of the other commands. import and batch apply their changes immediately and are skipped in check mode; nothing is staged for a later commit. Use this module’s structured commands (set, delete, section, and so on) whenever you need check mode, diff or transactional behaviour.

Examples

# Set a value
- community.openwrt.uc_uci:
    command: set
    config: uhttpd
    section: main
    option: max_connections
    value: "150"

# Read a value
- community.openwrt.uc_uci:
    command: get
    config: uhttpd
    section: main
    option: max_connections
    register: result

# Find or create a wifi-iface section, then delete it
- community.openwrt.uc_uci:
    command: section
    config: wireless
    type: wifi-iface
    name: ap0
    find:
      device: radio0
      ssid: My SSID
    value:
      encryption: none

- community.openwrt.uc_uci:
    command: absent
    config: wireless
    type: wifi-iface
    find:
      ssid: My SSID broken

# A batch of operations in a single call, spanning multiple configs and
# sections. Finish with commit to persist everything at once.
- community.openwrt.uc_uci:
    operations:
      - command: set
        config: system
        section: system
        option: hostname
        value: myrouter
      - command: set
        config: network
        section: lan
        option: ipaddr
        value: 192.168.1.1
      - command: set
        config: network
        section: lan
        option: netmask
        value: 255.255.255.0
      - command: add
        config: network
        type: interface
        name: wan6
      - command: set
        config: network
        section: wan6
        option: proto
        value: dhcpv6
      - command: commit

# Mask sensitive options in the diff output
- community.openwrt.uc_uci:
    command: section
    config: network
    type: interface
    name: wg0
    value:
      private_key: "very-secret-key"
      listen_port: "51820"
    redact_keys:
      - private_key
    diff: true

Return Values

Common return values are documented here, the following are the fields unique to this module:

Key

Description

changes

dictionary

Pending UCI changes, as returned by uci changes.

Returned: when command=changes

command

string

Command executed.

Returned: always

Sample: "section"

config

string

Config part of key.

Returned: when given

Sample: "wireless"

diff

dictionary

Structured diff keyed by config and section name, with before and after option maps for the changed sections. Sensitive options listed in redact_keys are masked.

Returned: when diff mode and changes were detected

operations

list / elements=string

Results of the executed operations, when used.

Returned: when operations is used

option

string

Option part of key.

Returned: when given

Sample: "ssid"

result

string

Output of the uci command.

Returned: always

Sample: "cfg12523"

result_list

list / elements=string

The list form of result.

For command=find_all, this is the list of matching positional section IDs, for example @wifi-iface[0]. Named sections are returned as positional IDs.

Returned: when command=get or command=find_all

Sample: ["0.pool.ntp.org", "1.pool.ntp.org"]

section

string

Section part of key.

Returned: when given

Sample: "@wifi-iface[0]"
