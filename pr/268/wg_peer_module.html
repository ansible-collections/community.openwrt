community.openwrt.wg_peer module – Manage WireGuard/AmneziaWG peer UCI sections

Note

This module is part of the community.openwrt collection (version 1.8.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install community.openwrt. You need further requirements to be able to use this module, see Requirements for details.

To use it in a playbook, specify: community.openwrt.wg_peer.

New in community.openwrt 1.8.0

Synopsis

  • Writes WireGuard/AmneziaWG peer UCI sections for an interface.

  • Takes the peer’s resolved key material (public key, optional PSK, endpoint) from controller facts; the interface itself must already exist (see community.openwrt.wg_interface).

  • Implemented in ucode and run directly on the OpenWrt target.

Note

This module has a corresponding action plugin.

Requirements

The below requirements are needed on the host that executes this module.

  • ucode and ucode-mod-uci on the target.

Parameters

Parameter

Comments

peer_id_tpl

string

Ucode template for the peer UCI section id.

Rendered with the iface_name, section and proto values in scope.

Default: "{% if (section): %}peer_{{ iface_name }}_{{ section }}{% else %}peer_{{ iface_name }}{% endif %}"

peers

list / elements=dictionary / required

List of peer configurations to write.

allowed_ips

list / elements=string

List of allowed IPs/prefixes.

Default: ["0.0.0.0/0", "::/0"]

description

string

Peer description/label.

endpoint_host

string

Peer endpoint host. Empty to omit (spoke does not dial).

endpoint_port

integer

Peer endpoint port.

iface

string / required

Parent interface name.

persistent_keepalive

integer

Peer persistent keepalive interval. Empty to omit the option.

preshared_key

string

Peer pre-shared key (optional). Never generated by this module; it is supplied by the caller (resolved/shared by community.openwrt.wg_interface).

proto

string

Peer protocol; the peer section type becomes <proto>_<iface>.

Defaults to the interface’s proto when not specified.

Choices:

  • "wireguard" ← (default)

  • "amneziawg"

public_key

string / required

Peer public key.

route_allowed_ips

string

Whether to add routes for the peer’s allowed IPs (OpenWrt route_allowed_ips).

Default: "0"

section

string

Peer section suffix, available as section in the peer_id_tpl template scope when deriving the peer section id.

state

string

Whether the peer section should be present or absent.

When absent, the peer section is removed.

Choices:

  • "present" ← (default)

  • "absent"

Attributes

Attribute

Support

Description

check_mode

Support: full

Can run in check_mode and return changed status prediction without modifying target.

diff_mode

Support: full

Returns details on what has changed (or possibly needs changing in check_mode), when in diff mode.

platform

Platform: OpenWrt

Target platform for this module.

Notes

Note

  • This module writes peer UCI sections only; it does not establish tunnels.

  • The peer section id is rendered from peer_id_tpl and must match the id used by community.openwrt.wg_interface when resolving pre-shared keys.

  • Template options (peer_id_tpl) use ucode’s native template engine (Jinja-style {{ ... }} / {% ... %}).

See Also

Examples

# Hub: write peer sections for two spokes on the wg0 interface
- community.openwrt.wg_peer:
    peers:
      - iface: wg0
        section: spoke1
        public_key: "AFakeSpoke1PublicKey"
        preshared_key: "AFakeSpoke1Psk"
        endpoint_host: "spoke1.example.com"
        endpoint_port: 51820
        allowed_ips:
          - "10.8.0.2/32"
      - iface: wg0
        section: spoke2
        public_key: "AFakeSpoke2PublicKey"
        preshared_key: "AFakeSpoke2Psk"
        endpoint_host: "spoke2.example.com"
        endpoint_port: 51820
        allowed_ips:
          - "10.8.0.3/32"

# Two independent p2p links: one peer per link interface (no section)
- community.openwrt.wg_peer:
    peers:
      - iface: wg_l1
        public_key: "AFakeLink1PeerPublicKey"
        preshared_key: "AFakeLink1PeerPsk"
        endpoint_host: "link1-peer.example.com"
        endpoint_port: 51821
        allowed_ips:
          - "10.9.0.2/32"
      - iface: wg_l2
        public_key: "AFakeLink2PeerPublicKey"
        preshared_key: "AFakeLink2PeerPsk"
        endpoint_host: "link2-peer.example.com"
        endpoint_port: 51822
        allowed_ips:
          - "10.10.0.2/32"

Return Values

Common return values are documented here, the following are the fields unique to this module:

Key

Description

diff

list / elements=dictionary

List of before/after diffs (pre-shared keys redacted), one entry per changed peer section.

Returned: when diff mode and changes were detected

peers

list / elements=string

Names of the (re)written peer sections.

Returned: always

removed

list / elements=string

Names of peer sections removed because peers[].state was absent.

Returned: when any peer state is absent
